# knowledge/

Reference notes accumulated while working on this repo — design patterns,
algorithms, database and security notes, a domain glossary, and the question
bank behind the `/interview` workflow.

**The contents of this directory are deliberately not committed.** It is study
and reference material for an individual, not documentation of this project.

Documentation that describes InferBolt itself belongs in committed locations
instead:

- [`../context/`](../context/) — architecture, API contracts, database schema,
  tech stack, deployment, known issues, roadmap.
- [`../../README.md`](../../README.md) — what the project is and how to run it.
- [`../../CONTRIBUTING.md`](../../CONTRIBUTING.md) — how to work on it.
- [`../skills/`](../skills/) — executable runbooks for recurring tasks such as
  drift triage, migration scaffolding, and cutting a release.

If a note here turns out to be about the project rather than about a general
concept, move it into `context/` so it ships.
